# Wire and neon placement implementation plan

> Use superpowers:executing-plans to implement this plan inline.

**Goal:** Reconstruct placed regular and neon wires, with surface routing and the documented 20/16 stud limits.

**Architecture:** Optional wire metadata preserves old projects. Shared route rules feed preview and commit; instanced tube, end and bend geometry shares materials. Neon illumination has a fixed light budget. Electrical topology remains bidirectional.

**Tech stack:** TypeScript, Three.js, Vitest, Playwright.

**Design:** Extend the existing Wire panel with Regular/Neon, neon colors, length feedback and Finish. Click surfaces to start/bend, sockets or wires to connect, Finish/Enter to terminate at the last surface point. Backspace removes bends and Escape cancels. Geometry is based on placed-wire photographs, not the misleading coil box thumbnail. Exact diameters remain reconstruction estimates. Preserve legacy routes when loading; new typed routes have placement and movement length constraints.

- [x] Implement wire-design rules, optional metadata and atomic world movement checks.
- [x] Extend Wire controls and live previews; test free endpoints, mounted routes, invalid routes, cancellation and save/reload.
- [x] Render separate regular/neon thickness, enlarged ends, powered/off colors, violet without bloom, and bounded illumination. Inspect actual browser output and test stable instance/light counts.
- [x] Run core/browser checks and production build; review changes, privacy scan and add a public-UI release verifier for Pages.

Review focus: old unlimited routes, partial group moves stretching wires, routing at plot seams, repeated points/zero segments, and walking near powered neon after switching/loading.

Implementation record: 165 core tests, 24 browser checks across wiring/logic/lighting, and the production wire verifier passed. Empty render batches initially exposed a missing color attribute; initialization now keeps the shader layout stable. Review findings led to mixed-radius junctions, route bounds on moves/copies, wire-only plot occupancy, single-component wire duplication and consistent rejected-move controls. Regression tests reproduced those failures before correction. Wire-only builds also retain the project's replacement confirmation.

Ruling: new endpoint contact uses visible tube radii because neon cannot share a regular wire's lower centerline on the ground without sinking into the floor. Legacy-to-legacy tolerance stays unchanged. Exact diameters and glow remain documented visual estimates. Ruling: a fixed two-light pool approximates game SurfaceLights to honor the performance goal.

Release: publish through the existing Pages workflow, then run `scripts/verify-wires-live.mjs` with `TIMBER_URL` set to the public site; it uses public UI only, checks both budgets/colors/export/reload, captures a screenshot and rejects WebGL errors.
