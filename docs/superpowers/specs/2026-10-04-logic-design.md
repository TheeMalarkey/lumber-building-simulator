# Logic foundation

Implement the requested accurate 3D logic as a complete first circuit-building milestone: Lever, Button, Pressure Plate, AND/OR/XOR/NAND/NOR/XNOR/Signal Inverter, Signal Delay and Signal Sustain. Wire them to each other and existing light switches. Further boards, displays, sensors and machinery remain follow-on integrations, not decorative nonfunctional catalog entries.

Use Circuit Workbench as the behavior reference: Boolean gates, bidirectional wire nets with any-high resolution, exact scheduled signal edges, 350 ms button pulse, delay settings 1–12 at 200 ms each, sustain setting 1 pass-through and 2–12 holding 400–2400 ms. Mark these values as simulator parity, not measured live-game guarantees. Detect unsettled feedback and report it; never freeze the render loop. Reconstruct inspected game thumbnails: chamfered gray gate shells and side symbols, top output arrow, dark/blue sockets, orange button and lever grip, distinct stopwatch/hourglass timer faces and wooden pressure plate. Dimensions remain visibly estimated until measured.

Separate pure circuit state from placement and renderer data. Persist components, configuration and anchored polyline wires with version-1 optional fields. Old builds must load unchanged. Runtime pulses reset on load, switches retain their saved state. Undo includes wires; deleting a component removes attached wires atomically; copies retain internal links but never wire back into originals. External wire paths remain attached to moved ports. Crossing line interiors do not connect; shared ports and deliberately placed endpoints connect.

Provide Wire mode: select a socket, optional surface bends, then another socket or wire junction. Escape cancels. Component inspector supplies source action, timer setting and socket buttons; walk mode can operate selected sources. Lights use externally driven state while wired and return to their manual setting when disconnected. Pressure plates respond to the walking avatar. Keep fixed material finishes and all placement constraints.

Performance: cached wire topology, resolve only on source/topology/timer events, bounded feedback work, instanced static parts and wire segments; dynamic signals must not rebuild the whole build or modify saved history. Validate gate tables, pulse duration, sustain retrigger, shared drivers, feedback, rotated sockets, save/load, deletion/undo, group-copy links, UI wiring, walk sensors, GPU errors and compact layout. Publish after checks using existing authorized main/Pages workflow.
